# Benchmarks

This directory contains;

* [Evaluation](./evaluation/) - code to evaluate the English rule based tagger for accuracy, coverage, speed, and resource requirements, against the current pre-built model, so that we can check whether a change makes the tagger better or worse.
* [Resource benchmarking](./resource_benchmarking/) - code to generate resource requirement statistics and semantic tagging throughput/speed, e.g. Amount of memory required to run the taggers and how fast they run both on CPU and where appropriate GPU.
